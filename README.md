# Himanshu Mishra — Professional Student Portfolio

A modern, responsive portfolio built for **Himanshu Mishra**, 2nd-Year Computer Science & Engineering student at Lovely Professional University (LPU) and Coordinator Head at Student Organization Vibranta.

## 🚀 Tech Stack
- **Framework**: React + Vite
- **Styling**: Vanilla CSS with CSS Variables & Glassmorphism
- **3D Graphics**: Three.js / `@react-three/fiber` / `@react-three/drei`
- **Animations**: Framer Motion
- **Icons**: Lucide React

## 📦 Getting Started

```bash
# Install dependencies
npm install

# Run local development server
npm run dev

# Build production bundle
npm run build
```

## 🛠️ Project Structure
- `src/components/HeroSection.jsx`: Professional profile showcase with photo & key stats
- `src/components/SkillsGrid.jsx`: Categorized technical competencies
- `src/components/ProjectCards.jsx`: Highlights of AI Planner, Weather Dashboard, and DSA Visualizer
- `src/components/ExperienceBar.jsx`: Vibranta Coordinator Head leadership details
- `src/components/ContactStrip.jsx`: Quick contact cards & inquiry form
- `src/components/BackgroundCanvas3D.jsx`: Interactive Three.js particle canvas background
